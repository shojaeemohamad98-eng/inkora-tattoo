# وضعیت پروژه

آخرین بررسی: 2026-09-27. فاز ۷ هفت صفحهٔ ویژهٔ RTL با visualهای انتزاعی CSS و progressive enhancement اضافه کرد: `/machines`، `/needles`، `/inks`، `/aftercare`، `/stencil`، `/accessories` و `/about`. اتصال واقعی WooCommerce فاز ۴ برقرار است، اما هنوز فقط محصول تست داخلی و ناموجود وجود دارد؛ بنابراین صفحات ویژه، انتخاب‌گر و مقایسه empty state صادقانه نشان می‌دهند.

اتوماسیون Codex با نام «Inkora phase handoff monitor» فعال شد. این پایش روزانه فقط پس از تکمیل واقعی فاز و تأیید صریح مدیر/کاربر، گزارش خلاصه را به چت مدیریت می‌فرستد و چت فاز بعدی را برای همان پروژه شروع می‌کند؛ تا آن زمان اقدامی انجام نمی‌دهد.

| فاز | خروجی مصوب | وضعیت |
|---|---|---|
| ۱ | زیرساخت | کامل؛ سایت `inkora.test.local`، WooCommerce 11.1.2، Inkora Core و API/فرانت‌اند واقعی تأیید شد |
| ۲ | طراحی و دارایی‌ها | کامل؛ tokens، RTL/responsive، preview، logo reference و manifest آماده‌اند؛ دارایی‌های واقعی در انتظار دریافت/تأیید هستند |
| ۳ | صفحه اصلی مطابق تصویر و موبایل | کامل در محدودهٔ نمونهٔ محلی؛ check/build/test و HTTP سه مسیر موفق، QA در 1440/768/390/320؛ عکس‌ها و لوگوی نهایی در انتظار دریافت |
| ۴ | فروشگاه محلی، سبد و مسیرهای خرید | کامل در محدودهٔ بدون درگاه؛ افتتاح مسدود تا درگاه sandbox و کالای واقعی |
| ۵ | پیشنهاد محصول، مقایسه و شبیه‌ساز | کامل در محدودهٔ دادهٔ واقعیِ فعلی؛ برای نتیجهٔ عملی، محصولات واقعیِ موجود و metadata لازم‌اند |
| ۶ | محتوای AI با بازبینی انسانی | کامل در محدودهٔ review-first؛ بدون API AI یا انتشار خودکار |
| ۷ | صفحات ویژه و 3D سبک | کامل در محدودهٔ نمونهٔ محلی؛ CSS 3D/visual انتزاعی، بدون مدل واقعی، عکس خارجی یا WebGL |
| ۸ | جامعه هنرمندان | شروع نشده |

افتتاح فقط پس از فاز ۴ و آزمون کامل خرید. کنترل‌های فازهای پیشرفته تا آماده‌شدن با توضیح غیرفعال خواهند بود؛ صفحه آزمون فاز ۱ چنین کنترل‌هایی ندارد. بررسی headless درگاه و تبدیل تومان/ریال در ابتدای مسیر فروشگاه انجام می‌شود.
