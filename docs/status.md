# وضعیت پروژه

آخرین بررسی: 2026-09-27. **فاز ۲ کامل شد**؛ سیستم طراحی، قفل مرجع برند، manifest دارایی و پیش‌نمایش محلی آماده‌اند. WooCommerce، Inkora Core، محصول تست و اتصال واقعی frontend نیز از فاز ۱ تأیید شده‌اند.

اتوماسیون Codex با نام «Inkora phase handoff monitor» فعال شد. این پایش روزانه فقط پس از تکمیل واقعی فاز و تأیید صریح مدیر/کاربر، گزارش خلاصه را به چت مدیریت می‌فرستد و چت فاز بعدی را برای همان پروژه شروع می‌کند؛ تا آن زمان اقدامی انجام نمی‌دهد.

| فاز | خروجی مصوب | وضعیت |
|---|---|---|
| ۱ | زیرساخت | کامل؛ سایت `inkora.test.local`، WooCommerce 11.1.2، Inkora Core و API/فرانت‌اند واقعی تأیید شد |
| ۲ | طراحی و دارایی‌ها | کامل؛ tokens، RTL/responsive، preview، logo reference و manifest آماده‌اند؛ دارایی‌های واقعی در انتظار دریافت/تأیید هستند |
| ۳ | صفحه اصلی مطابق تصویر و موبایل | شروع نشده؛ باید براساس سیستم طراحی فاز ۲ و دارایی‌های تأییدشده ساخته شود |
| ۴ | فروشگاه کامل، آزمون درگاه و افتتاح | شروع نشده |
| ۵ | پیشنهاد محصول، مقایسه و شبیه‌ساز | شروع نشده |
| ۶ | محتوای AI با بازبینی انسانی | شروع نشده |
| ۷ | صفحات ویژه و 3D سبک | شروع نشده |
| ۸ | جامعه هنرمندان | شروع نشده |

افتتاح فقط پس از فاز ۴ و آزمون کامل خرید. کنترل‌های فازهای پیشرفته تا آماده‌شدن با توضیح غیرفعال خواهند بود؛ صفحه آزمون فاز ۱ چنین کنترل‌هایی ندارد. بررسی headless درگاه و تبدیل تومان/ریال در ابتدای مسیر فروشگاه انجام می‌شود.
