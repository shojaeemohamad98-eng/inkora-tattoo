# ابزارهای خرید هوشمند — فاز ۵

آخرین به‌روزرسانی: 2026-09-27.

## آنچه اکنون عملی است

- `/advisor` فقط محصول منتشرشده، موجود و دارای متادیتای معتبر را می‌خواند. قاعدهٔ رتبه‌بندی صریح است: ۲ امتیاز برای سطح مهارت یکسان و ۱ امتیاز برای سبک ثبت‌شده. اگر تطبیق مستند نباشد، نتیجه‌ای نمایش نمی‌دهد.
- `/compare?products=12,15` حداکثر سه محصول از یک گروه را مقایسه می‌کند. شناسه‌ها فقط عدد مثبت، یکتا و محدود به سه هستند؛ هیچ اطلاعات حساس در URL نیست.
- `/simulator` فقط در مرورگر کار می‌کند. فایل JPEG/PNG/WebP تا ۵MB با `URL.createObjectURL` پیش‌نمایش می‌شود و با drag، scale، rotate و opacity تغییر می‌کند. فایل به سرور، WordPress یا AI ارسال یا ذخیره نمی‌شود. سطح فعلی یک placeholder انتزاعی است، نه پوست یا پیش‌بینی نتیجه.

## ورود دادهٔ مدیر

برای هر کالای واقعی در WooCommerce، محصول را منتشر و موجود کنید و در تب **Inkora smart shopping** این مقادیر را وارد کنید:

| گروه | فیلد لازم | واحد/مقادیر مجاز |
|---|---|---|
| machine | نوع، استروک، بازه ولتاژ | `pen`/`rotary`/`coil`؛ mm (۱–۵)؛ V (۱–۲۰) |
| needle | پیکربندی، تعداد، قطر | حروف مانند RL/RM؛ ۱–۹۹؛ mm (۰٫۱۵–۰٫۵) |
| ink | نوع و خانواده رنگ | `lining`/`shading`/`color`/`greywash`؛ slug عمومی |

برای هر گروه، سطح (`beginner`، `intermediate`، `professional`) و سبک‌های پشتیبانی‌شده (`linework`، `shading`، `color`، `blackwork`، `realism`، `traditional`) اختیاری‌اند، اما بدون آن‌ها انتخاب‌گر تطبیقی نمی‌سازد. تکنیک‌ها comma-separated و کوتاه‌اند. یادداشت تأمین‌کننده، قیمت خرید و دادهٔ داخلی هرگز وارد این فیلدها نشود.

افزونه `inkora-core` نسخهٔ ۰٫۲٫۰ متادیتا را validate/sanitize می‌کند و فقط برای محصولات منتشرشده و موجود، همان metadata عمومی محدود را با Store API برمی‌گرداند. محصول `INKORA-PHASE-01` به‌صراحت حذف می‌شود. ذخیرهٔ فرم محصول از nonce استاندارد WooCommerce و capability `edit_post` استفاده می‌کند؛ endpoint seed نیز از nonce REST و `manage_woocommerce` استفاده می‌کند.

## محدودیت‌ها

- نبود داده، نتیجه یا مشخصات جایگزین تولید نمی‌کند.
- شبیه‌ساز background removal، warp پوست، تصویر پوست واقعی، AI، upload backend، ذخیره و خروجی دانلود ندارد.
- پیش از استفاده از عکس پوست واقعی، رضایت مکتوب و حق استفاده لازم است.
