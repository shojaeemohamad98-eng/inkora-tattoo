# مرجع داخلی برند

`logo-04-preview.png` فقط برش طرح ۰۴ از تصویر ارسالی کاربر است. این پوشه منبع لوگوی نهایی یا مجوز انتشار عمومی نیست. برش با System.Drawing بدون بزرگ‌کردن، بازطراحی یا حذف نشان انجام شد. مشخصات منبع و crop در `docs/design-system.md` آمده است.

مرجع صفحه اصلی فقط از مسیر اصلی کاربر خوانده شد؛ فایل چندطرحی کامل، عکس‌ها و لوگوهای دیگر آن وارد مخزن نشده‌اند.
