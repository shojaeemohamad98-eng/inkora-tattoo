# تحویل فاز ۷ — صفحات ویژه و تعامل سبک

تاریخ: 2026-09-27. ریشهٔ پروژه: `C:\Users\moham\Local Sites\inkora tattoo`.

## خروجی

- هفت صفحهٔ ویژهٔ فارسی/RTL: دستگاه، سوزن، رنگ، aftercare، استنسیل، اکسسوری و دربارهٔ Inkora.
- visualهای CSS محلی و انتزاعی: آناتومی دستگاه/سوزن، پالت رنگ، workspaceهای stencil/accessory و شش لایهٔ داستانی about.
- selectorهای نمایشیِ accessible برای دستگاه/سوزن/رنگ، با لمس، کلیک، صفحه‌کلید، aria state و reset.
- Home و footer به مسیرهای واقعی صفحات ویژه پیوند داده شدند. هیچ کنترل پیشین فعال یا تغییر رفتار تجاری داده نشد.
- کالاها فقط از کلاینت مرکزی WooCommerce می‌آیند و صرفاً هنگامی نمایش داده می‌شوند که واقعی، منتشرشده، موجود و دارای گروه یا دستهٔ ثبت‌شده باشند.

## محدودیت‌های آگاهانه

هیچ مدل یا تصویر سه‌بعدی واقعی، عکس stock، hotlink، WebGL، Three.js، GSAP، video، صوت، ادعای محصول، توصیهٔ پزشکی یا بازنمایی شخص/اثر واقعی وجود ندارد. `/aftercare` فقط مسیر کالاها و مقاله‌های تأییدشده است. وضعیت فعلی فروشگاه کالاهای واجدشرایط ندارد؛ بنابراین empty state انتظار درست سیستم است.

## بررسی‌ها

- `pnpm check`: صفر خطا و صفر هشدار.
- `pnpm test`: 11 آزمون موفق، شامل اعتبارسنجی routeهای فاز ۷ و فیلتر محصولات واقعی/موجود.
- `pnpm build`: build محلی ساخته شد؛ اندازه‌ها و بودجه در [experiences.md](../experiences.md) ثبت شده‌اند.
- HTTP 200 برای هفت route جدید، Home، Shop، Design System، Journal، Advisor، Compare و Simulator.
- مرورگر محلی در 1440/768/390/320 بررسی شد؛ overflow افقی نبود. تعامل selector و reset با صفحه‌کلید تأیید شد.

## روش دیدن نسخهٔ محلی

در PowerShell و ریشهٔ پروژه اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\pnpm.ps1 dev
```

سپس آدرس نشان‌داده‌شده در ترمینال را باز کنید؛ در این اجرا `http://127.0.0.1:5176/machines` فعال بود. برای بقیه، فقط بخش آخر را تغییر دهید: `/needles`، `/inks`، `/aftercare`، `/stencil`، `/accessories` یا `/about`.

برای نسخهٔ واقعی‌تر، لوگوی نهایی مجاز، عکس/مدل محصول با حق انتشار، اطلاعات واقعی WooCommerce و در صورت نیاز رضایت اشخاص و آثار لازم است. فقط Git محلی استفاده شد؛ push، deploy، hosting یا تغییر سایت قدیمی انجام نشده است.
