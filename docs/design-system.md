## نقشهٔ responsive برای صفحهٔ اصلی فاز ۳

مرجع فقط دسکتاپ است؛ موبایل پیشنهاد طراحی است و ادعای pixel-perfect ندارد. breakpointها: mobile=320–767، tablet=768–1199، desktop≥1200؛ زیر 480 کارت preview تک‌ستونه. مقادیر media query به علت محدودیت CSS custom property در شرط query صریح نوشته شده‌اند.

ترتیب DOM: header → hero و اقدام اصلی → خدمات تأییدشده → دسته‌ها → بخش‌های محصول/راهنما → الهام و مقاله → footer. بخش‌های پیشرفته فقط با وضعیت صریح غیرفعال و توضیح یا حذف کامل تا فاز مربوط؛ در فاز ۲ شبیه‌ساز/AI ساخته نشده است.

## RTL و معیارهای پذیرش

- سند lang=fa، wrapper dir=rtl؛ استفاده از margin/padding/inset-inline و ترتیب DOM طبیعی. متن لاتین و SKU و کد hex در bdi یا dir=ltr؛ ترتیب عدد قیمت با Intl.NumberFormat('fa-IR').
- حداقل متن عمومی 16px، توضیح 14px؛ 12px فقط برچسب غیرحیاتی. زوم نباید محتوای اصلی را حذف کند.
- تمام عملیات با صفحه‌کلید، focus واضح، skip-link، سلسله‌مراتب h1/h2/h3، label فرم و توضیح خطا لازم‌اند. disabled جای دسترسی به توضیح علت را نمی‌گیرد.
- هدف contrast: متن عادی ≥4.5:1 و متن بزرگ/مرز کنترل ≥3:1. نمونه رنگ‌ها با محاسبه بررسی می‌شود؛ این به معنی ممیزی کامل WCAG نیست.
- هدف تصویر فاز ۳: hero WebP/AVIF حداکثر حدود 250KB، دسته 60KB، ابعاد ثابت برای جلوگیری از جابه‌جایی؛ hero eager و تصاویر پایین lazy. فایل اصلی مجاز جدا نگهداری شود.
- preview هیچ درخواست WooCommerce، checkout یا AI ندارد؛ ورودی و toggle صرفاً حافظهٔ همان صفحه‌اند.
