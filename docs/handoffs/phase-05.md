## خروجی

- افزونهٔ `inkora-core` ۰٫۲٫۰ مدل metadata محدود برای دستگاه، سوزن/کارتریج و رنگ دارد و آن را تنها برای کالاهای منتشرشده، موجود و غیرتستی به Store API اضافه می‌کند.
- مدیر فروشگاه در تب «Inkora smart shopping» ویرایش محصول، گروه، سطح مهارت، سبک‌ها، تکنیک‌ها و مشخصات دارای واحد را وارد می‌کند. ورودی‌ها sanitize و validate شده و ذخیره با capability و nonce استاندارد WooCommerce محافظت می‌شود.
- `/advisor` مسیر RTL با فرم قابل‌دسترسی، خلاصه و روش رتبه‌بندی روشن دارد. بدون تطبیقِ داده‌ای، نتیجه نمی‌سازد.
- `/compare` حداکثر سه کالای هم‌گروه را با URL قابل اشتراک و بدون داده حساس مقایسه می‌کند.
- `/simulator` آپلود محلی JPEG/PNG/WebP تا ۵MB، drag، scale، rotate، opacity و reset دارد؛ هیچ انتقال شبکه، WordPress، AI یا ذخیره‌سازی ندارد. به علت نبود عکس واقعیِ دارای رضایت، فقط placeholder انتزاعی نشان می‌دهد.

## وضعیت کنونی داده

تنها محصول `INKORA-PHASE-01` ناموجود و داخلی است و به‌صراحت از catalog، پیشنهاد و مقایسه حذف می‌شود. به همین دلیل advisor و compare اکنون حالت خالی راهنمای مدیر نشان می‌دهند؛ این رفتار مورد انتظار و صادقانه است، نه خطا.

## بررسی‌ها

- `pnpm check`: صفر خطا و صفر هشدار.
- `pnpm test`: ۸ آزمون موفق؛ شامل rules رتبه‌بندی، گروه مقایسه، URL و ریاضی transform.
- `pnpm build`: موفق با adapter-node.
- HTTP 200 برای `/advisor`، `/compare`، `/simulator`، `/shop` و `/design-system` تأیید شد.
- health سایت Local پاسخ `inkora-core` نسخهٔ `0.2.0` و WooCommerce فعال داد.
- PHP CLI در این محیط در PATH موجود نبود؛ نحو افزونه باید در PHP همان LocalWP نیز هنگام بازکردن پیشخوان بررسی شود. `git diff --check` بدون مشکل اجرا شد.
