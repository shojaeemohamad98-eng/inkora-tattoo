# محتوای AI-assisted با بازبینی انسانی — فاز ۶

## اصل کار

این فاز **موتور تولید متن یا اتصال به سرویس AI ندارد**. هیچ API key، نام کاربر، prompt خصوصی یا محتوای تولیدشده به سرویس بیرونی ارسال نمی‌شود. اگر تیم از ابزار AI بیرونی برای نوشتن پیش‌نویس استفاده کند، مسئولیت ورود دستی متن و بررسی آن با مدیر WordPress است.

## روند امن انتشار

1. در WordPress یک نوشتهٔ جدید بسازید و متن را به‌صورت **Draft** نگه دارید.
2. در باکس `Inkora AI content review`، گزینهٔ `This draft used AI assistance` را فعال کنید.
3. منابع بررسی‌شده، اصلاحات و محدودیت‌ها را در `Private review notes / sources checked` بنویسید. این یادداشت در API عمومی نیست.
4. بازبین انسانی باید تصمیم `approved` را انتخاب کند. تا پیش از آن، تلاش برای انتشار به draft برمی‌گردد.
5. فقط پس از بررسی واقعیت‌ها، حق استفاده از تصویر/متن، قیمت و موجودی واقعی، و نبود ادعای پزشکی یا مراقبتیِ تأییدنشده، نوشته را منتشر کنید.

`/journal` تنها نوشته‌های منتشرشده‌ای را نشان می‌دهد که هم AI-assisted و هم `approved` هستند. نمایش مقاله، نام نویسنده، یادداشت خصوصی، prompt، منابع داخلی یا هر secret را برنمی‌گرداند.

## مرزها

- AI نباید قیمت، موجودی، مشخصات محصول، برند، رتبه‌بندی، تجربهٔ کاربر یا توصیهٔ پزشکی را بسازد.
- برای aftercare و سلامت، فقط متن بازبینی‌شده توسط فرد واجدصلاحیت منتشر شود؛ این سیستم جای مشاورهٔ پزشکی نیست.
- هیچ انتشار خودکار، زمان‌بندی‌شده یا بدون بازبین وجود ندارد.
- اگر مقاله‌ای ندارید، `/journal` حالت خالی صادقانه دارد.
